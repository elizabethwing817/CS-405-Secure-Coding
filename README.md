# CS-405 Secure Coding

**Course:** CS-405 – Secure Coding  
**University:** Southern New Hampshire University

---

## Overview

This repository contains coursework and projects completed for CS-405 Secure Coding at Southern New Hampshire University.

The course focused on identifying software vulnerabilities, applying secure coding standards, and implementing security practices throughout the software development lifecycle. Assignments emphasized C++ programming, vulnerability prevention, automated testing, and organizational security policies.

## Repository Contents

- **Project One – Security Policy:** A security policy developed for Green Pace, outlining secure coding standards, risk management, and recommended security practices.
- **Project Two – Security Presentation:** A presentation addressing the importance of incorporating security throughout software development, including automated unit testing.
- **Coding Assignments:** ZIP files containing C++ programming activities focused on identifying and preventing common security vulnerabilities.
- **Portfolio Reflection:** A journal reflecting on secure coding standards, risk assessment, zero trust, and security policy implementation.

## Technologies and Concepts

## Skills Demonstrated

- Identifying and addressing common software vulnerabilities
- Applying secure coding principles to C++ development
- Testing invalid inputs and boundary conditions
- Evaluating security risks and mitigation strategies
- Developing organizational security policies
- Communicating security recommendations

## Key Takeaways

CS-405 expanded my practical understanding of secure software development. While I was already familiar with many security concepts from previous courses, working directly with C++ vulnerabilities and automated testing helped me better understand how those principles apply to actual code.

One of my biggest takeaways was the importance of incorporating security throughout development rather than treating it as a final step. As I continue toward a career in software development, I plan to apply secure coding standards, automated testing, and vulnerability prevention practices to future projects.
